使い方

請求書を作って送る

  1. 「① 請求書をつくる」で、宛先・件名・中身・金額を入れる
  2. 「できあがりを見る」で見た目を確かめる
  3. 「PDFを作る」→「LINE・メールなどで送る」
  4. 出てきた一覧から LINE や Gmail を選んで、相手に送る

すぐ開けるようにする（最初に1回）

  1. Chromeの右上の「︙」を押す
  2. 「ホーム画面に追加」を押す → ホーム画面にアイコンができる

困ったら

  • 入れたデータはこのスマホの中だけに残ります（「これまでの請求書」で見られます）
  • Chromeの「履歴やデータを消す」をするとデータも消えるので、ときどき「会社の情報」→「控えを保存」をしてください

請求書をPDFにする

  1. 「① 請求書をつくる」で、宛先・件名・中身・金額を入れる
  2. 「できあがりを見る」を押して、見た目を確かめる
  3. 「PDFにする」を押す
  4. 出てきた画面の「送信先」を 「PDFに保存」 にして「保存」
  5. 保存する場所は 「デスクトップ」 を選ぶ（あとで探しやすい）

PDFをスマホに送る（Googleドライブ）

  1. できあがり画面の「Googleドライブを開く」を押す
  2. 左上の 「＋新規」→「ファイルのアップロード」 を押す
  3. 「デスクトップ」を選んで、さっきのPDFを選び「開く」
  4. スマホで 「ドライブ」アプリ を開くと、PDFが入っている
  5. PDFの右の「︙」→「共有」または「送信」→ LINE やメールを選んで相手に送る

困ったら

  • 入れたデータは、このパソコンに自動で残ります（「これまでの請求書」で見られます）
  • このファイル（請求書づくり.html）の場所や名前を変えないでください。データが見えなくなることがあります
